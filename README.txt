Bible Explorer - 3D galaxy of the 66 books

How to run:
1. Unzip this folder.
2. Open index.html in any modern browser (Chrome, Edge, Firefox, Safari).

Notes:
- It is a single self-contained page. All book data and King James Version verses are inside index.html.
- An internet connection is needed the first time to load the 3D library (three.js) and the fonts.
- Controls: drag to orbit, scroll or pinch to zoom, click a book to read its verses, arrow keys to step through books, Esc to zoom out.
